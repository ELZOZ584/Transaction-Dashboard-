🚍 Transaction Dashboard – Excel Analytics
This repository contains an interactive Transaction Dashboard built entirely in Microsoft Excel using advanced formulas, charts, and dynamic visuals. The dashboard provides insights into passenger activity, bus utilization, route performance, and time-based travel behavior.

📌 Overview
The dashboard helps transportation teams quickly understand:
How many passengers travel across the network
Which routes are busiest vs. least busy
Peak and off-peak passenger hours
How buses are utilized (over, under, or well utilized)
Rider distribution across months and weekdays
AM vs. PM passenger trends
YOY (Year-over-Year) changes
The design focuses on clarity, dark-mode usability, and real-time insights.
